# 🔥 FACEIT Font Switcher

Change the font style of **FACEIT** with one click.

Choose from gaming, modern, condensed and decorative fonts with **Latin + Cyrillic support**.

[![GitHub](https://img.shields.io/badge/GitHub-Repository-black?style=for-the-badge&logo=github)](https://github.com/frz13/FACEIT-Font-Switcher)

##  Features

-  300+ fonts
-  Latin + Cyrillic support
-  Instant font switching
-  Saves your selected font
-  Reset fonts with one click
-  Optional custom localization
-  Designed for FACEIT's dynamic interface
-  Add u fonts in favorite

##  Installation

Install [Tampermonkey](https://www.tampermonkey.net/) or [Orangemonkey](https://chromewebstore.google.com/detail/orangemonkey/ekmeppjgajofkpiofbebgcbohbmfldaf/), then install the script:

**[👉 Install FACEIT Font Switcher](https://update.greasyfork.org/scripts/592591/FACEIT%20Font%20Switcher.user.js)**

Open FACEIT → Profile → **Change Font**.
